# SVETLOVE — версия 2

Статический сайт для GitHub Pages: главная, каталог, карточка товара, мобильная версия.

## Как обновить существующий сайт

1. Скачайте ZIP, распакуйте.
2. В GitHub откройте репозиторий `svetlove-studio`.
3. Загрузите **содержимое** папки `svetlove-v2` в корень репозитория (index.html, style.css, script.js, assets/), заменив прежние файлы.
4. После публикации откройте https://lilyasamsonova.github.io/svetlove-studio/ и обновите страницу.

**Важно:** до загрузки новых файлов сохраните копию старой версии. GitHub Pages должен быть настроен на ветку `main`, папка `/ (root)`.

## Каталог через Google Таблицу

В `script.js` замените пустую строку в `GOOGLE_SHEET_CSV_URL` на ссылку CSV, опубликованную из Google Таблицы. Пока ссылка пустая, показываются демонстрационные товары из макетов.

Поддерживаемые столбцы: `id,name,category,price,description,height,width,depth,image,image_2,image_3,image_4,image_5,status,visible`.

`category`: Зима, Весна, Лето, Осень, Детство, Корпоратив. `visible`: да или нет. Фото должны иметь прямые публичные URL (не ссылку на страницу просмотра Google Drive).

Кнопки «Купить» и «Задать вопрос» пока открывают Instagram студии — позже замените на нужный канал заказа. Фотографии извлечены из PDF-макетов; для публикации лучше заменить их на оригиналы в высоком качестве.
