SVETLOVE — каталог из Google Таблицы

1. Откройте index.html для просмотра макета.
2. Для надёжной загрузки CSV опубликуйте сайт на GitHub Pages: при открытии локального HTML браузер может блокировать сетевые запросы.
3. В Google Таблице Products используйте столбцы: id, name, category, price, description, image, status, visible.
4. category: winter, spring, summer, autumn или yearround.
5. visible: TRUE (показать) или FALSE (скрыть).
6. image: публичная прямая ссылка на файл изображения (jpg/png/webp). Ссылки на страницы просмотра Google Drive могут не работать как изображения.
7. Пока таблица пустая, показываются демонстрационные карточки.
8. Кнопки заказа пока открывают почтовое приложение. Для WhatsApp/VK требуется реальная ссылка на нужный аккаунт.
9. Таблица опубликована в интернете: не добавляйте в неё персональные данные покупателей.
